# ldl805

Specialized utilities for Linux environments, embedded single-board systems, low-latency streaming pipelines, and wireless network monitoring.

---

### Focus & Active Environments

- **Linux & Shell Scripting:** Custom system administration, environment deployment, and terminal workflow optimization.
- **Embedded & SBCs:** Raspberry Pi platforms, hardware telemetry, and remote peripheral integration.
- **Video & Audio Pipelines:** RTSP/low-latency stream handling, API integration, and headless operations.
- **Wireless Tooling:** Interface state management, packet capture prep, and auditing utilities.

---

### Featured Repositories

#### [stream-matrix](https://github.com/ldl805/stream-matrix)
Custom multi-channel RTSP video streaming framework designed for low-latency ingest, matrix display, and headless Linux configurations.

#### [EZMonitorModeButton](https://github.com/ldl805/EZMonitorModeButton)
Lightweight Linux desktop/CLI utility providing single-action interface management to cycle supported Wi-Fi adapters between managed and monitor modes for network analysis, packet capture, and security auditing workflows.

#### [QuickSpeechPi](https://github.com/ldl805/QuickSpeechPi)
Raspberry Pi-focused text-to-speech engine leveraging Gemini TTS API models for fast, local-trigger synthetic voice delivery.
